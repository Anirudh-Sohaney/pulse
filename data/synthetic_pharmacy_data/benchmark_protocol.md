# Transparent benchmark protocol

This package is a reproducible synthetic stress test for pharmacy-demand
forecasting. It is not a transaction extract from an Arkansas pharmacy and
must not be presented as observed clinical or commercial data.

The current file contains one modeled local-government clinic and 30 drug
series. It is therefore a single-site benchmark, not evidence of performance
across multiple pharmacies or Arkansas facilities. Any multi-pharmacy claim
requires a separately generated multi-site panel or observed validation data.

## What the benchmark is designed to show

The benchmark asks whether model-derived signals improve a pharmacy forecast
when demand contains documented seasonal, access, outbreak, and supply events.
The result is a conditional capability demonstration, not evidence that the
model caused or predicted an observed market outcome.

## Required publication disclosures

Every external presentation should state:

- the sales file is synthetic and generated by
  `generate_synthetic_pharmacy.py`;
- the generator seed, source code revision, and generator hash are recorded;
- event tags identify the modeled drivers and are available for audit;
- signals are aligned by their actual availability date, with no future values
  available to the forecaster;
- the holdout period was not used for feature selection, threshold selection,
  or model tuning;
- results are reported against a sales-only baseline and include uncertainty
  across drugs and time windows.

## Recommended evaluation design

1. Regenerate the CSV from the pinned generator and verify row count, date
   range, product count, and nonnegative counts.
2. Freeze the signal table before looking at the final test period.
3. Use the first 60% of dates for training, the next 20% for validation, and
   the final 20% as an untouched test period.
4. Select signals and tune hyperparameters using training and validation only.
5. Compare at least: seasonal-naive, sales-only XGBoost, all-signal XGBoost,
   and a pre-registered sparse-signal XGBoost variant.
6. Report pooled and unweighted per-drug MAE, RMSE, WAPE, sMAPE, R², and the
   fraction of forecasts within 5%, 10%, and 20% error.
7. Repeat with event tags removed or permuted. This ablation measures how much
   of the apparent gain depends on each documented scenario family.
8. Repeat with signal dates shifted later by a safety buffer. This checks that
   the gain is not caused by timestamp leakage.

## Interpretation standard

The result is publishable as a transparent synthetic stress-test result when
the signal model beats the sales-only baseline on the untouched test period,
the advantage persists across multiple drugs and event families, and the
ablation and timestamp checks do not invalidate it. If the advantage is small,
that should be reported plainly. A benchmark is more credible when it exposes
the conditions under which it succeeds and fails.

## Current status

This CSV includes recurring, dated late-summer outpatient COVID episodes in
2023, 2024, and 2025. They are separated from the fixed seasonal components,
are exposed through product-level tags, and begin after the prior August
signal period. This creates an auditable test of whether dated external
signals add useful information beyond the clinic's historical sales.

Run `python3 data/synthetic_pharmacy_data/evaluate_current_benchmark.py` after
regenerating the CSV. It invokes the repository's unchanged untouched-test
implementation and writes `current_benchmark_metrics.json` and
`current_benchmark_results.md` in this directory. Metrics generated for a
previous CSV must not be reused.

For the current deterministic artifact, the untouched final-period run gives
the sparse signal model 29.40% WAPE and the sales-only model 32.35% WAPE.
The deduplicated sparse check gives 29.03% WAPE. These numbers are specific to
the documented synthetic scenarios and should be interpreted alongside the
event tags, timing constraints, and the full metric table rather than as an
estimate of live pharmacy performance.

The signal table includes annual and near-static variables, including exact
duplicate daily series in this small panel. Interpret only the documented
deduplicated/sparse robustness output as evidence about independent,
time-varying inputs.
